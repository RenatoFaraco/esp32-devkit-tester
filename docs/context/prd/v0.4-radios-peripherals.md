# PRD — esp32-devkit-tester v0.4 · Rádios e periféricos

> Status: **rascunho** · Marco: M4

## Objetivo
Testar o que depende do rádio e dos pinos, respeitando o que cada chip tem.

## Escopo previsto
| ID | Requisito |
|----|-----------|
| R1 | Wi-Fi: scan, contagem de APs e RSSI (2,4 GHz; 5 GHz no C5) |
| R2 | BLE: anunciar e/ou escanear |
| R3 | IEEE 802.15.4 (C5, C6, H2): rádio sobe e recebe energia do canal |
| R4 | P4: comunicação com o coprocessador de rádio da DevKit, quando houver |
| P1 | LED/RGB da placa e botão BOOT (interação na TUI: "o LED piscou? [y/n]") |
| P2 | GPIO em loopback com jumper opcional (perfil de placa) |
| P3 | ADC com referência conhecida (opcional) |

## Em aberto
Perfis de placa (pinos de LED, botão, jumpers) — formato do arquivo e onde mora.
