# PRD — esp32-devkit-tester v0.3 · JTAG

> Status: **rascunho** · Marco: M3

## Objetivo
Verificar que o JTAG funciona em cada placa: o TAP responde, o núcleo para e volta, a memória
e os registradores lidos pelo JTAG batem com os lidos pela UART.

## Já decidido
- USB-Serial/JTAG embutido em C3, C5, C6, S3, P4 e H2; no ESP32 original só com sonda externa
  (ESP-Prog/FT2232) nos GPIO12–15 → sem sonda, SKIP com motivo.
- Caminho técnico (OpenOCD-esp32 como processo vs probe-rs como biblioteca): ADR-006, proposta.

## Escopo previsto
| ID | Requisito |
|----|-----------|
| J1 | Detectar a interface JTAG da placa (USB nativo ou sonda FTDI) |
| J2 | Ler o IDCODE do TAP e comparar com o esperado do chip |
| J3 | Halt / resume / step em cada núcleo |
| J4 | Ler registradores e uma região de memória pelo JTAG e comparar com a leitura pela UART |
